### Planner Response

I have fixed the issue in `vite.config.js`!

### What caused the issue:
1. **HTML Dump File Interference**: Vite was automatically scanning all `.html` files in the root folder, including `wp_ditsolution_net.html` (the raw extracted WordPress file), which contained unparsed HTML entities like `&#34;`.
2. **Browser Auto-Open Permission**: `open: true` attempted to spawn a browser process without permissions (`EPERM`).

### The Fix:
I updated [vite.config.js](file:///C:/Users/murtaza.hassan/Music/Rewamp%20Project/vite.config.js) to explicitly set `index.html` as the sole entry point and disabled automatic browser spawning:

```javascript
export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
    open: false
  },
  optimizeDeps: {
    entries: ['index.html']
  },
  build: {
    rollupOptions: {
      input: 'index.html'
    }
  }
})
```

Now, simply re-run the development server in your terminal:
```bash
npm run dev
```

Then open **[http://localhost:3000](http://localhost:3000)** in your browser!
